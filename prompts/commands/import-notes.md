# /import-notes

이력서만으로도 리뷰는 된다. 이 명령은 **이력서에 아직 안 쓴 경험과 흩어진 할 일**을 찾아 프로필을 채우는 선택 단계다.

## 0. 먼저 묻는다 (사용자 동의 없이는 아무것도 읽지 않는다)
1. 활용할지: "메모·노트에 있는 경험과 할 일을 `{PROFILE}`에 정리할까요? 읽기만 하고 원본은 바꾸지 않습니다."
2. 소스와 범위: 어떤 소스를, 어느 폴더·워크스페이스까지 읽을지. **제외할 곳**(일기, 감정 기록, 회사 기밀, 이력서 사본 등)도 묻는다.
3. 읽을 수단이 있는지 확인한다. 없으면 설치·연결 방법만 안내하고 대신 설치하지 않는다.

| 소스 | 읽는 방법 (읽기 전용) |
|---|---|
| Notion | Notion MCP 연결 (검색·조회만) |
| Obsidian | vault 폴더 경로를 받아 md 파일 읽기 |
| Apple 메모·미리 알림 (macOS) | `osascript`로 목록·본문 출력만 (쓰기 명령 금지) |
| 로컬 파일 | 사용자가 준 경로의 md, txt, pdf |
| GitHub | 사용자가 준 저장소의 README, 커밋 |

## 1. 읽을 때 규칙
- **원본에 쓰지 않는다.** 생성·수정·삭제·이동 명령을 쓰지 않는다.
- **비밀값은 옮기지 않는다.** 토큰, 비밀번호, API 키, 개인 식별 번호를 보면 값은 적지 않고 **위치만** 사용자에게 알린다(교체 권장).
- 감정·건강·가족 같은 사적인 내용은 옮기지 않는다. 판단이 애매하면 묻는다.
- 원문을 통째로 복사하지 않는다. 필요한 사실만 요약하고 출처 위치를 단다.
- 양이 많으면 소스·폴더 단위로 나눠 병렬로 읽되, 각 단위가 끝날 때마다 무엇을 읽었는지 기록한다.

## 2. 정리할 곳
| 찾은 것 | 넣을 곳 | 형식 |
|---|---|---|
| 이력서에 없는 경험, 수치, 장애·개선 사례 | `{PROFILE}/experience.md` | E번호, 기간, 상황·행동·결과, 수치(없으면 `[?]`), 출처 위치 |
| 기술 학습 기록 | `{PROFILE}/skills.md` | 스킬, 수준(0~3), 근거 |
| IT·커리어 할 일 | `{PROFILE}/todo-backlog.md` | 중복을 합치고 점수 = I × (1+G) ÷ E 로 정렬. 반복해서 적혔지만 끝나지 않은 항목은 표시 |
| 본인이 내린 방향 결정 | `{PROFILE}/todo-backlog.md` 맨 위 '방향' | 날짜와 함께 |
| 직접 받은 조언·유료 자료 요약 | `{PROFILE}/mentors/principles.yaml` | `mentors/principles.yaml` 형식, source_type: direct_advice |
| 관심 회사·공고 | `{PROFILE}/applications.md` 후보 섹션 | 회사, 이유, 링크 |
| 무엇을 언제 읽었나 | `{PROFILE}/log/import-YYYYMMDD.md` | 소스, 범위, 제외한 곳, 비밀값 발견 위치(값 없이) |

- `{PROFILE}/resume.md`는 **고치지 않는다.** 이력서에 넣을 만한 내용은 백로그의 서류(A) 항목으로 제안만 한다.
- 끝나면 사용자에게 요약한다: 새 경험 몇 개, 할 일 몇 개(상위 5개), 비밀값 발견 위치, 읽지 못한 곳.
