# 평가 데이터와 지표 신뢰 수준

| 지표 | 현재 값 | 상태 | 독립 검증에 필요한 것 |
|---|---|---|---|
| 기술 추출 F1 (`extract_score.json`) | 0.969 (30건) | **예비** | 라벨을 Claude가 붙였고, 같은 30건으로 규칙을 보정함 → (1) 사용자 검수 (2) 보정에 쓰지 않은 새 표본 |
| 정밀 분석 인용 정확도 | 인용 전문 대조 통과분만 저장 | 존재만 검증됨 | 해석의 타당성(축·필수/우대 분류)은 30개 표본 수동 검수에서 90% (Claude 판정) |
| 리뷰 모델 비교 (`eval/results`) | Haiku·Sonnet 비교 1건 | **파이프라인 확인용** | 정답 문제 목록이 임시본(provisional). 실제 멘토 라벨과 사람 채점 시트 필요 |

## 사용자 검수 방법 (기술 추출)
1. `extract_gold.jsonl`의 각 줄을 확인합니다. 정답 기술(`gold_skills`)과 최소 경력이 맞는지 봅니다.
2. 틀린 부분은 고치고 `labeler`를 `user`로 바꿉니다.
3. `.venv/bin/python -m crawler.eval_extract score`를 실행합니다. 결과에 `independent_labels`가 늘어난 것을 확인합니다.

## 보정에 쓰지 않은 표본 만들기 (다음 수집 후)
```bash
.venv/bin/python -m crawler.eval_extract sample --n 30   # 기존 라벨과 겹치지 않는 공고만 추가됨
```
- 새로 추가된 30건으로는 **규칙을 고치기 전에 먼저 점수를 잽니다.**
- 그 점수가 독립 정확도입니다.
